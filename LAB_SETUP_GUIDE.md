# Ghana Hospital EMR - Lab Module Setup Guide

## Quick Start

### 1. Run Seed Scripts (Database Population)

```bash
cd /home/dei-gratia-server/Documents/lhims

# Run in this order:
python3 seed_comprehensive_ghana_reference_ranges.py
python3 seed_ghana_additional_lab_templates.py
python3 seed_lab_reports_dhims2.py
```

All scripts are **idempotent** - safe to re-run (won't create duplicates).

---

## Accessing the Lab Module

### Option A: Web UI (EMR)

1. **Start the application** (if not running):
   ```bash
   cd /home/dei-gratia-server/Documents/lhims
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

2. **Open browser** to: `http://localhost:8000`

3. **Navigate to Lab Module**:
   - Login with your credentials
   - Go to **Ancillary Services** → **Lab Dashboard**
   - Or use the main menu: **Lab** → **Lab Orders**

4. **Order a new test**:
   - Click **New Lab Order** or **Walk-in Order**
   - Search for test by name (e.g., "Stool Culture", "FBC")
   - Select the test template
   - Fill in patient details

5. **Enter results**:
   - Go to **Lab Orders** → Find the order
   - Click **Enter Results**
   - The template will show with reference ranges

---

### Option B: Print Lab Forms (PDF)

The forms are generated by running:
```bash
python3 seed_lab_reports_dhims2.py
```

This prints:
1. **Lab Request Form** - For clinicians to order tests
2. **Lab Report Form** - For lab to report results  
3. **DHIMS2 Monthly Summary** - For data aggregation

To save as PDF:
```bash
# Save to file
python3 seed_lab_reports_dhims2.py > lab_forms.txt

# Convert to PDF (if needed)
# Use browser: File → Print → Save as PDF
```

## Troubleshooting

### Reference ranges not showing?
- Make sure the test has numeric fields
- Check the field code matches in template and reference range
- Run: `python3 seed_comprehensive_ghana_reference_ranges.py`

### New templates not appearing?
- Refresh the browser (Ctrl+F5)
- Clear browser cache
- Check database: `SELECT * FROM lab_templates`

### Need to add more tests?
1. Create a new seed script following existing patterns
2. Or manually add via the Admin UI
