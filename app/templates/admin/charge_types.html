How Charge Types Work

Charge types are used throughout the system to categorize services and billing items. When you add a new charge type here, it will automatically appear in:

  • Service Pricing management
  • Invoice creation forms
  • Billing reports and dashboards

Note: The system will use your configured charge types. If none are configured, it falls back to the default set.
